# tools/ — 維運輔助工具

## rpz_health_check.sh — RPZ 運作健康檢查（唯讀）

| 項目 | 內容 |
|---|---|
| 對象 | OP / 監控人員 |
| 性質 | 唯讀。不修改任何檔案、設定與排程 |
| 相依 | 無。單檔即可，獨立於 RPZ 程式本身 |
| 執行時間 | 約 2 秒 |

### 傳檔與執行

```bash
scp tools/rpz_health_check.sh tools/rpz_health_check.sh.sha256 admin@<設備IP>:/var/tmp/
```

設備上核對與執行：

```bash
cd /var/tmp && sha256sum -c rpz_health_check.sh.sha256
```

```bash
bash /var/tmp/rpz_health_check.sh
```

### 檢查項目（8 項）

1. 排程狀態（active / 300 秒）。
2. 排程最近 15 分鐘內有沒有實際執行。
3. 最近 12 次執行的成功與失敗次數。
4. 黑名單結果檔：三檔時間一致性（完整更新的特徵）與新鮮度。
5. 暫存檔數量是否受控（每類上限 24）。
6. /config 磁碟使用率（70% 注意、80% 異常）。
7. 本機是否有 RPZLocal 事件（Splunk 可視性）。
8. rpztw 資料是否已載入 DNS 服務。

### 判讀

| 退出碼 | 畫面判定 | 動作 |
|---|---|---|
| 0 | [正常] | 不需處理 |
| 1 | [注意] | 先觀察；持續出現再回報 |
| 2 | [異常] | 保留完整畫面輸出回報 |

### 備註

1. 新鮮度門檻預設 24 小時。黑名單來源可能整天沒有變更，
   所以新鮮度超時只給[注意]，要搭配第 2、3 項判讀。
2. 門檻可用環境變數調整：`RPZ_FRESH_HOURS`（小時）、
   `RPZ_KEEP`（暫存檔上限，需與 main.sh 設定一致）。
